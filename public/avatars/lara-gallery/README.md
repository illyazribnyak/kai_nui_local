# Галерея Лари — кидай сюди свої зображення

Ця папка **автоматично** підхоплюється грою (API `/api/lara-gallery` → картка Лари → «Галерея»).

## Що робити

1. Згенеруй портрети (SD / Civitai / тощо) з референсом `../lara.png`.
2. Поклади файли сюди:
   - формати: `.jpg` `.jpeg` `.png` `.webp`
   - імена: латиниця, наприклад `lara_wet_shirt.jpg`, `boudoir_01.png`
3. Закоміть і запуш (або лише локально).
4. Онови сторінку гри — з’являться в **Стати → картка Лари → Галерея**.

## Не класти сюди

- Контент з порн-сайтів / Reddit без ліцензії (не в git).
- Сирі гігабайтні raw — краще стиснути до ~1–2k px.

## Слоти тіла (конструктор)

Окремо: AI/stock у `../body/`.  
Опційно лише локально: `../body/private/` (gitignore) — якщо з’явиться підтримка, див. `lib/game/lara-body-kit.ts`.
