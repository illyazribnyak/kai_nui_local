License: [Mixkit License (SFX Free)](https://mixkit.co/license/#sfxFree) — free for commercial and personal use, no attribution required.

Stored as compressed previews for game size; looped in the client.

| File | Role | Mixkit source (approx.) |
|------|------|-------------------------|
| `ambient-ocean.mp3` | Ocean / beach ambience | Sea waves with birds loop |
| `ambient-jungle.mp3` | Jungle birds ambience | Birds in the jungle |
| `ambient-tribal.mp3` | Tribal drums pulse | Drumming jungle music |
| `ambient-amulet.mp3` | Magical / mystical bed | Magic SFX pack |
| `sfx-click.mp3` | UI click | Interface / click |
| `sfx-dice.mp3` | Dice roll | Game / randomizer |
| `sfx-success.mp3` | Achievement unlock | Win / success |
| `sfx-craft.mp3` | Crafting / woodwork | Wood knock |
| `sfx-newday.mp3` | New day chime | Win / fanfare soft |

To replace: drop new `.mp3` files with the **same filenames** into this folder.
